# Сортироовка (шаблоны)
## Линейная сортировка
```
Есть int arr[],int n
int i, j, min_idx, temp;
// Перебираем элементы массива
for (i = 0; i < n - 1; i++) {
    // Находим минимальный элемент в неотсортированной части
    min_idx = i;
    for (j = i + 1; j < n; j++) {
        if (arr[j] < arr[min_idx]) {
        min_idx = j;
    }
}
// Меняем минимальный элемент с первым элементом
temp = arr[min_idx];
arr[min_idx] = arr[i];
arr[i] = temp;
}
```
### Основные особенности
Принцип: На каждом шаге ищется минимальный элемент и помещается в начало.
Сложность: В худшем, среднем и лучшем случае — O(n^2), так как выполняются вложенные циклы.
Применение: Эффективна только на небольших массивах, так как работает медленнее, чем qsort или сортировка слиянием. 

## Пузырьковая сортировка
```
Есть int arr[], int n
int i, j, temp;
for (i = 0; i < n - 1; i++) {
    // Последние i элементов уже отсортированы
    for (j = 0; j < n - i - 1; j++) {
        // Сравнение соседних элементов
        if (arr[j] > arr[j + 1]) {
        // Обмен элементами (swap)
        temp = arr[j];
        arr[j] = arr[j + 1];
        arr[j + 1] = temp;
        }
    }
}
```
